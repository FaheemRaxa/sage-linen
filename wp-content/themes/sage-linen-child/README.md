# Sage Linen Child Theme

This child theme adds the premium Sage Linen homepage while preserving the existing Flatsome parent theme and WooCommerce templates.

## Activation

1. Activate **Sage Linen Child** in WordPress.
2. Assign a static homepage under Settings > Reading.
3. Clear LiteSpeed and browser caches.
4. Validate shop, product, cart, checkout, My Account, wishlist, payment, and mobile navigation flows.

The official logo is stored at `assets/images/sage-linen-logo.png` and is referenced by the child theme stylesheet for desktop header, mobile header, and footer logo selectors. The PNG is used as supplied without recreation, recolouring, cropping, or distortion.

The homepage uses native WordPress and WooCommerce queries for categories and products. It does not modify products, categories, orders, checkout, payment settings, or WooCommerce plugin files.
