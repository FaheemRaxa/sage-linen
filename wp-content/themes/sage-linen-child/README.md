# Sage Linen Child Theme

This child theme adds the premium Sage Linen homepage while preserving the existing Flatsome parent theme and WooCommerce templates.

## Activation

1. Upload the official Sage Linen logo to the child theme at `assets/images/sage-linen-logo.png`, or configure it under WordPress Customizer > Site Identity.
2. Activate **Sage Linen Child** in WordPress.
3. Assign a static homepage under Settings > Reading.
4. Clear LiteSpeed and browser caches.
5. Validate shop, product, cart, checkout, My Account, wishlist, payment, and mobile navigation flows.

The current repository did not include the official uploaded logo asset, so the template uses the configured WordPress custom logo and falls back to the existing parent theme logo asset. No logo has been recreated or substituted with generated artwork.

The homepage uses native WordPress and WooCommerce queries for categories and products. It does not modify products, categories, orders, checkout, payment settings, or WooCommerce plugin files.
